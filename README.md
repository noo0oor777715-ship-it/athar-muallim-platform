# أثر معلم

منصة رقمية متكاملة لتكريم المعلمين والمعلمات وإبراز أثرهم في بناء الإنسان وصناعة المستقبل.

## التشغيل

```bash
npm install
npm run prisma:generate
npm run prisma:push
npm run dev
```

## الميزات الأساسية

- صفحة رئيسية احترافية
- نموذج إرسال الرسائل والمشاركات
- جدار الوفاء الرقمي
- لوحة المشرف
- نظام مراجعة واعتماد المحتوى
- الدعم الفني والتقييم
- أمان أساسي وتحسين إمكانية الوصول
